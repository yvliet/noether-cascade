# Cascade for Flint

Organize notes into sequential cascades (books) with status-bar linking, graph backlinks, and custom sidebar folders.

## 1. Installation
---

Install directly within Flint from the **Community Extensions Marketplace** or place into your Hearth's `.flint/extensions/flint-cascade/` folder.

## 2. Building Locally
---

```bash
npm install
npm run build
```
